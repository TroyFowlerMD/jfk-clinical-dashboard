Epic Workflows

Admission
Admission Activity Tab → Admission Navigator

Admission Documentation

  • Problem List — Update once evaluation is complete. Mark the principal problem.
  • Allergies — Confirm with patient and make necessary additions. Mark as Reviewed.
  • Consents — Complete on admission if the patient is prescribed buprenorphine, methadone, or antipsychotics that we are likely to continue. Search sp: "MOUD" (bup, methadone) or sp: "Psychotropic Medications Consent" (antipsychotics).
  • PDMP Status — Review PDMP. Mark as Reviewed.

History

  • Med/Surg, Family — Review nursing entries. Document Family Psych History.
  • Psychiatric History — Document thoroughly. For patients with extensive treatment histories, it's acceptable to consolidate multiple treatments into a single entry as long as pertinent information is captured.
  • Substance Use Details — Review nursing screening documentation and update as needed. Drug section: make a selection (yes/not currently/never) for "Drug use" and skip subsequent subsections. Class section MUST be completed for Primary, Secondary, and Tertiary substance of choice — this is a Federal requirement. Complete [Drug] Details for each current and historic substance.
  • Social History — Complete. Ensure Gender Identity is accurate for gender minorities.
  • Trauma History — Record categories of traumas and approximate age. Avoid documenting sensitive details here (reserve those for the evaluation note if clinically appropriate).

Place Admission Orders → Admission Orders

  • Reconcile home meds — Every home medication must be addressed: continue, don't continue, or order and hold.
  • Order Sets:
    • JFK ADATC Admission ACU or ARS Order Set (if primary care hasn't completed first)
    • SUD Monitoring and Treatment Order Set (contains all detox protocols, MOUD, and MAUD)

Notes and Assessments

  • Comp Psych Eval — Also accessible via: Notes tab → New Note → Comp Psych Eval. SmartPhrase: sp: .JFKACUADMISSIONPSYCHIATRY or sp: .JFKARSADMISSIONPSYCHIATRY
  • Treatment Plan — Select Add Care Plan (unless one already exists). Add a plan for each problem requiring active management. IP Substance Use should apply to every patient.
    • Add at least one Long-term goal — choose from list or use sp: .JFKPSYLTG. End date: "t+365"
    • Add at least one Short-term goal — choose from list or use sp: .JFKPSYSTG. End date: "t+7" (ACU) or "t+14" (ARS)
    • Add at least one Intervention per STG — choose from list or use sp: .JFKPSYINT. Select a measurable frequency (not "as needed")
    • Set the effective date 30 days out so the care plan does not expire
    • Select Plans → Start a New Plan → Multidisciplinary Treatment Plan
  • By end of shift: Update Handoff and Hospital Course (both in Sidebar). SmartPhrases: sp: .JFKHANDOFF and sp: .JFKHOSPITALCOURSE

Admission Pearls

  • Orders signed in Admission Orders are held until patient arrives on unit. If a med is needed ASAP in the admissions hall, use the Orders activity or + ADD ORDER button, then notify admissions nursing immediately.
  • Once evaluation is complete, prioritize writing admission orders and updating the problem list — this enables nursing to deliver a thorough handoff and expedite their admission process.
  • AIMS exam MUST be documented on admission for all patients currently on an antipsychotic (and at baseline before starting one). SmartPhrase: sp: .JFKAIMS (can be placed within the psych eval, progress note, or as a standalone note).
  • Referral documentation can be found in Media Manager (use the Search bar).
Follow Up
Progress notes and daily documentation
  • Notes tab → New Note → Progress Note. SmartPhrase: sp: .JFKACUPROGRESSNOTEPSYCHIATRY or sp: .JFKARSPROGRESSNOTEPSYCHIATRY
  • Always update Handoff and Hospital Course (Sidebar). SmartPhrases: sp: .JFKHANDOFF and sp: .JFKHOSPITALCOURSE

Follow Up Pearls

  • Use an existing progress note as your starting template via the copy button. Select the note type first. Verify all information is current before submitting.
  • For the first progress note, reference the Comp Psych Eval when selecting Psychosocial Stressors.
Transfer
ACU ↔ ARS unit transfers
  • Transfer tab → Transfer Orders: Click "Transfer Patient to new unit" order
    • Service: ADATC
    • Level of care: ACU → ARS is residential. For ARS → ACU diversion, select whichever LOC best applies
    • Review current orders for accuracy. Continue/DC/Modify as indicated
    • Activity level 3 for ARS; level 1 for ACU
    • Safety Check for ARS: q60m daytime, q30m nighttime
    • No detox protocols, CIWA/COWS, or frequent PRNs for ARS patients. Exceptions must be confirmed with attending. In these cases, always inform the nurse supervisor and provide a warm handoff (verbal report) to the ARS psych provider.
  • Notes tab → New Note → Progress Note. SmartPhrase: sp: .JFKTRANSFERSUMMARY
  • Treatment Plan tab → Manage Plan & Document Progress
    • → Document Progress: Update goals (Progressing, Adequate for Transfer, Completed)
    • → Manage Plan: Add additional STG + Intervention if needed (ensure at least one of each applies to rehab). Create a new plan (can carry forward the first one) → Plans → Start a New Plan → Multidisciplinary Treatment Plan
  • Update the Handoff to clearly convey upcoming plans, recommendations, and action items.
Discharge
Ideally complete everything the day before, except signing the discharge summary

Discharge Tab

  • Complete CSSRS Discharge Screener
  • Update Problem List — ensure all SUDs have severity specifiers
  • Discharge Orders:
    • Discharge Med Rec (done by primary care, except for unplanned after-hours discharges)
    • Bridge prescription buprenorphine (when applicable)
    • Click Discharge Patient order → Select Routine Discharge → Enter anticipated discharge date
    • Order Sets → Psychiatry Discharge Order Set
    • Personalize Psychiatry Discharge Instructions (can delete "Monitoring" section if primary care is contributing to the discharge; for after-hours, complete as best you can)
    • Add "How to Use Naloxone" discharge instructions, if applicable
  • Discharge Summary → Create Note. SmartPhrase: sp: .JFKDISCHARGESUMMARY. Pro tip: reference the psych eval for Psychosocial Stressors, Suicide Risk, and Violence Risk sections. Make updates as applicable.

Treatment Plan

  • Treatment Plan tab → Document Progress → Resolve Plan. Goal closure guidance:
    • "Adequate for Discharge" — the patient has achieved the goal (e.g., detox complete or symptoms minimal)
    • "Completed" — we are no longer managing that goal because they are leaving our care. The treatment episode is complete. This does not imply the goal was fully achieved.
    • If a patient is leaving with minimal progress and the problem remains tenuous (e.g., leaving against advice at the peak of withdrawal), document a brief note describing the situation. That note type is found in Treatment Plan tab → Summary and Note.

Discharge Pearls

  • The discharge summary does not have to be finished before the patient leaves — prioritize orders and patient instructions so the AVS is ready.
  • A pended discharge summary cannot be edited by a new author, but it can be easily copied into a new note.
  • SmartPhrase sp: .EDLABS provides a more condensed and readable labs report than the default options. Feel free to substitute it anywhere in Epic.
  • Nursing executes the discharge order when all workflows are complete. If there's any uncertainty about whether the patient is actually leaving, still place the order and complete the full workflow — the order can be discontinued at any time.
Admission Denial (formerly EMTALA)
Patient presents for evaluation but is not admitted

This workflow applies to any patient who presents for evaluation but is not admitted for any reason. Nuances vary by reason — if unclear, discuss with your attending or psych backup provider.

  • Discharge tab → Admission Denial subtab: Complete basic navigator sections (allergies, SUD history, medical history)
  • Notes tab → New Note → SmartPhrase: sp: .JFKMEDICALSCREENINGEXAMFOREMTALA
  • Consents → search "EMTALA Transfer" → complete consent with the patient

If the patient is NOT being transferred for an EMTALA emergency

  • If appropriate, order a Nursing Communication for naloxone (NOT a prescription to our pharmacy). Search orders for "Nursing Communication" and add the comment: "Please dispense OTC naloxone rescue kit with patient education"
  • Discharge tab → Admission Denial → Instructions for AVS → add SmartPhrase: sp: JFKCRISISRESOURCELIST. At the top of that section, include personalized follow-up recommendations.
  • Do NOT place a discharge order — the patient was never admitted. Nursing removes the patient from the facility in Bed Manager.
Afterhours Admission
On-call admission workflow
  • Notes tab → New Note → Progress Note → SmartPhrase: sp: .JFKONCALLADMISSION
  • Admission tab → Admission Navigator → Place admission orders (refer to the standard Admission workflow above)
Significant Event
Events requiring documentation outside of a typical progress note

Use this note type for events that require documentation outside of a typical progress note. This note type stands out during chart review and is trackable data in Epic.

Use for

  • Significant withdrawal complications (e.g., seizure, DTs) leading to an LOA to Mission
  • LOA to Mission for any reason
  • Patient injury (fall, physical altercation, etc.)
  • Behavioral discharge
  • Problematic behaviors leading to a behavioral treatment team and/or partnership agreement

Do NOT use for

  • Routine withdrawal complications (e.g., repeated vomiting episodes, distress intolerance, yelling in room/milieu)

Steps: Notes tab → New Note → Significant Event Note. Update Handoff and Hospital Course as appropriate.

Computer Folders/Files to Know
Key network drives and documents
  • Pre-admission Treatment Planning — S:\PRIVATE\Pre-Admission Treatment Planning (password: drugs). Contains notes on patients with prior issues (behavioral, withdrawal complications) that should be carefully considered before admission. Check this document for all after-hours walk-ins before completing your evaluation. Staff the case with your attending/backup if any questions about appropriateness.
  • Pharmacy Formulary — S:\PUBLIC\Pharmacy\Formulary
  • MOUD Directory — S:\PRIVATE\MOUD Directory. Contains the OTP/OBOT directory spreadsheet (often more direct contact lines than main numbers) and a list of OTPs accepting walk-in intakes.
  • Partnership Agreement — S:\PUBLIC\Downtime Documents & Procedures\Epic Downtime\Provider Downtime Documents. Paper form for addressing treatment-interfering behaviors (pending Epic template). Do not modify the original file — save as new before editing. After completion, leave form by Unit Coordinator's computer with a sticky note reading "scan into patient's chart."
  • Epic Downtime Provider Documents — S:\PUBLIC\Downtime Documents & Procedures\Epic Downtime\Provider Downtime Documents
